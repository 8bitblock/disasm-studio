Added, Removed and Transfers display their own content without leaving an unrelated matched-function preview below them.

It covers populated feature views, actual authored-byte scanning, exact FILE-zero navigation, retained filtering, stale result retirement, compact layouts and palette/scale cases. The existing full workbench suite remains the broader shell/navigation check.
