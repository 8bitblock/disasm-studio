# UI refinement — 7 September 2026

- Narrow Binary View windows now open the evidence inspector in a bounded popup from the existing rail button. It uses the same instruction, paused-context and authorization-evidence validation as the wide inspector. Close, Escape and outside clicks dismiss it; navigation and Registers/Authorization handoffs close it to expose the destination. Popup resizing never changes retained pane width or manual collapse choices.
- Functions retains the current function highlight when selecting an instruction inside its body or an exactly owned distant chunk. LIVE selections highlight a FILE function only after exact image/module mapping succeeds. Invalid cursors, function-end gaps, unknown LIVE owners and unmapped FILE offsets do not select an unrelated row.
- Strings displays matching counts, scan progress, partial-result warnings and empty-state guidance above the scrolling results. Empty searches no longer leave an empty fill-height table ahead of their explanation. The shared search field supports Escape clearing. Filtering remains generation-cached and result rows remain clipped.
- The location breadcrumb reserves visible space for FILE/LIVE/FILE-offset provenance and the exact address. Long document/function context is elided with complete details on hover. The breadcrumb participates in Tab navigation; Space or a click copies the typed location and shows a brief confirmation. Invalid selections cannot copy. Workflow buttons use their measured widths when wrapping, including the monospace preset labels.
